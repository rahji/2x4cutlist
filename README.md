# 2x4cutlist

This is a webpage created entirely by Claude that draws a cutlist for parts to be cut from a 2x4.

I'm not a fan of using AI for coding projects but in this case, I just needed to insert diagrams of my cuts into an assembly manual for a frame made from 2x4's and this was the easiest way to get them.

*Note that this does not take into account the saw kerf. That was on purpose, but it's very important to know that this is the case!*
